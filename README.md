📦 Amazon Sales & Analytics Dashboard
📊 Project Overview

This project focuses on analyzing Amazon sales data to uncover meaningful business insights related to revenue, orders, customer behavior, and product performance.
The goal was to transform raw transactional data into a clear, interactive, and decision-ready dashboard using Power BI.

This project is part of my continuous learning journey in data analytics and business intelligence, with an emphasis on data storytelling and dashboard design.

🎯 Objectives

Analyze overall sales performance and trends

Identify high-revenue categories and products

Understand monthly and yearly sales patterns

Track key performance indicators (KPIs) for business monitoring

Build an interactive dashboard for quick insights

📌 Key KPIs

Total Revenue

Total Orders

Average Order Value (AOV)

Active Customers

Sales Trends (Monthly / Yearly)

📈 Dashboard Insights

The Power BI dashboard provides insights such as:

Sales trends over time (monthly & yearly)

Category-wise and product-wise revenue contribution

Order volume and revenue performance comparison

High-performing segments and seasonal patterns

The visuals are designed to be clean, intuitive, and business-focused, making it easy for stakeholders to understand performance at a glance.

🛠 Tools & Technologies Used

Power BI – Dashboard design & visualization

DAX – KPI and measure calculations

Power Query – Data cleaning & transformation

Python (Jupyter Notebook) – Exploratory Data Analysis (EDA)

Excel / CSV – Raw data handling
